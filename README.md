# Coffee_Coders_project
## **StudyShare**
## Team Name : Coffee Coders
**Problem Statement**
  Students don't have ease of access to notes,PYQ's or proper guidance on the subjects or even how to approach the exam.
**Solution**
  An online web platform for accessing and uploading notes, PYQs, references etc. Easily search with keywords to access the files needed which are uploaded by other users. Also provides a feature to chat with the peers and user who uploaded the note to ask doubts. Upvotes and downvotes to grade the notes uploaded and can be used to reccomend it to users based on the upvote count.
